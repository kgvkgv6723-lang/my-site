## Приветствие

- Ни один файл в репозитории не должен быть длиннее 500 строк. Если файл разрастается — создай новый файл и раздели содержимое.

## Задачи на следующую сессию

- В конце каждой сессии обновляй TASKS.md задачами на следующую сессию.
- В начале сессии читай TASKS.md; выполненное отмечай или удаляй.

## Сохранение сессии
- В конце каждого дня (и когда я говорю «заканчиваем») сохраняй итоги сессии в репозиторий: файл `sessions/ГГГГ-ММ-ДД.md` — что сделали, все тексты (контент-планы, посты) и решения.
- Контент-планы и готовые посты храни отдельными файлами в папке `content/` (например, `content/plan-14-dney.md`, `content/posts/ГГГГ-ММ-ДД.md`).
- Репозиторий на GitHub — это и есть облако: после сохранения делай commit и push.
- Не забывай обновлять TASKS.md задачами на следующую сессию.
